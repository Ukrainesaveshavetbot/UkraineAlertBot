# UkraineAlertBot

Telegram-бот і вебкарта для відображення лише офіційних регіональних статусів повітряних тривог.

Команди: `/start` — підписка; `/alerts` — останні статуси; `/map` — вебкарта; `/stop` — вимкнути сповіщення.

Потрібні змінні середовища `BOT_TOKEN` і `ALERTS_API_TOKEN`. Telegram-токен отримується у @BotFather; API-токен — за інструкцією https://devs.alerts.in.ua/. Не завантажуйте `.env` або токени до GitHub; додавайте лише `.env.example`.

Render: у репозиторії є `render.yaml`. Під час створення Blueprint задайте секретні змінні. Безкоштовний Web Service може засинати, тому безперервна робота 24/7 не гарантується.

Локально: `pip install -r requirements.txt`, потім `python bot.py`; карта відкриється на `http://127.0.0.1:8080`.

Дані можуть затримуватися й не замінюють сирени, офіційні застосунки та вказівки служб. Карта не відображає місце, напрямок чи маршрут безпілотників.
