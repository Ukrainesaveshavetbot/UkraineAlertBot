TELEGRAM-БОТ С ОФИЦИАЛЬНЫМИ СТАТУСАМИ ВОЗДУШНЫХ ТРЕВОГ

1. Установи Python 3.11 или новее с https://www.python.org/downloads/
   При установке отметь "Add Python to PATH".

2. В этой папке открой CMD (в адресной строке Проводника напиши cmd и нажми Enter).

3. Установи библиотеки:
   py -m pip install -r requirements.txt

4. Создай Telegram-бота через @BotFather командой /newbot.
   Скопируй токен бота.

5. Получи персональный API-токен alerts.in.ua по инструкции:
   https://devs.alerts.in.ua/developers
   Токен API — секрет; не публикуй его и не отправляй никому.

6. Скопируй файл .env.example и назови копию .env.
   Открой .env в Блокноте и вставь оба токена после знака "=".

7. Запусти:
   py bot.py

КОМАНДЫ В TELEGRAM
/start   — подписаться на уведомления
/alerts  — получить текущие статусы
/map     — адрес локальной карты
/stop    — отключить уведомления

КАРТА
Пока bot.py работает на этом компьютере, открой в браузере:
http://127.0.0.1:8080

ВАЖНО
- Бот работает только пока компьютер включён, подключён к интернету и запущен bot.py.
- Локальная карта доступна только на этом компьютере.
- Проверка API выполняется примерно раз в минуту.
- Данные могут поступать с задержкой. Бот не заменяет сирены, официальные приложения,
  сообщения ОВА и указания экстренных служб.
- Проект отображает только статусы тревог по областям; он не отслеживает координаты,
  маршруты или предполагаемое местоположение беспилотников.
